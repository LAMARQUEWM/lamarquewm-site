# La Marque WM — site v1

Première version du nouveau site indépendant de Shopify.

## Contenu
- `index.html` : page principale
- `styles.css` : design
- `products.js` : 11 produits + stock issu de l'export Shopify du 09/08/2026
- `app.js` : catalogue et panier local

## Important
Cette version est un prototype fonctionnel du front-end.
Le paiement Stripe n'est PAS encore activé.
Les images utilisent temporairement les URL du CDN Shopify afin de pouvoir tester immédiatement le rendu.
Elles seront remplacées ensuite par les copies locales sauvegardées dans le dossier de la marque.

Stock de référence : 105 pièces.
